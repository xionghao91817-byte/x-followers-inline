# X 粉丝数直显

在 X（Twitter）帖子作者的 **@ID 后面，直接显示粉丝数量**，浏览信息流时少一次打开主页的操作。

```text
用户名  @example · 12.3万粉丝 · 2小时
```

适合希望快速了解作者账号规模、连续浏览帖子和回复的用户。粉丝数只提供账号规模背景，不代表内容质量或可信度。

## 功能

- **和 ID 同行显示**：粉丝数紧跟 @ID，宽度不足时较长的 ID 省略显示。
- **中文数字**：少于 1 万显示完整数字，例如 `3,225粉丝`；1 万及以上显示为 `12.3万粉丝`，最多一位小数。
- **查看准确值**：将鼠标悬停在粉丝数上，查看完整数字及获取时间。
- **随页面更新**：新帖子加载后自动处理作者栏；支持 X 当前及部分历史用户数据格式。
- **本地运行**：不需要 API Key，不使用付费接口，不额外请求用户主页。

## 安装

本项目通过 GitHub 提供源码和 ZIP，目前没有上架浏览器扩展商店。

1. 从本项目的 **Releases** 下载 `x-followers-inline-1.0.0.zip`，解压到一个固定位置。
2. 打开浏览器扩展管理页：
   - Edge：在地址栏输入 `edge://extensions`。
   - Chrome：在地址栏输入 `chrome://extensions`。
3. 打开 **开发者模式**。
4. 点击 **加载解压缩的扩展 / 加载已解压的扩展程序**，选择解压后的插件文件夹。
5. 确认扩展名称为 **X 粉丝数直显**，刷新已登录的 X 页面。

**选择的文件夹里必须直接有 `manifest.json`。** 如果提示“清单文件丢失或不可读取”，通常是选中了外层文件夹，请再进入一层检查。

也可以点击仓库的 **Code → Download ZIP** 下载源码，解压后选择直接包含 `manifest.json` 的项目目录。

不要移动或删除已加载的文件夹，否则浏览器下次启动时可能无法加载插件。

## 使用

安装后按平常方式浏览 X，无需打开插件面板。

作者栏会显示 `@ID · 742粉丝` 或 `@ID · 12.3万粉丝`。插件只使用 X 网页已经加载的数据，因此获取不到数字时会显示 **粉丝待获取**，不会把未知数字当成 0。

若数字一直待获取，先刷新页面，再将鼠标悬停在作者名字或 ID 上，让 X 加载用户卡片。如果卡片请求返回了粉丝数，标签会随之更新。

更新插件时，替换固定文件夹内的插件文件，在扩展管理页点击该扩展的“重新加载”，然后刷新 X。若从新的文件夹加载，先禁用旧版本，避免两个版本同时运行。

## 浏览器与范围

- 需要 Chromium 111 或更高版本；用户已在 Edge 中确认粉丝数获取和同行显示效果。
- Chrome 使用相同的扩展格式，但本项目尚未完成独立的真实页面验收。
- 360 等其他 Chromium 浏览器的兼容性未确认；Firefox 尚未适配。
- 只处理 `x.com` 和 `twitter.com` 网页中符合作者栏结构的帖子。正文里的 @提及和私信联系人不在显示范围内。

## 隐私与权限

- 插件仅在 `https://x.com/*` 和 `https://twitter.com/*` 注入脚本和样式。
- 本插件不读取 Cookie，不存储密码，不把数据发送到外部服务器。
- 当前页面内存中只保留用户名、粉丝数和获取时间，刷新页面后清空。
- 不修改账号资料、不发帖、不自动关注、不点赞。

## 已知限制

- 数字是 **X 网页返回数据时的快照**，不是实时计数器。最多使用 30 分钟，之后等待网页返回新数据。
- 不保证所有作者都能立即显示：若网页未返回粉丝数字段，插件会保持待获取状态。
- X 网页结构或非公开数据字段改变后，可能需要更新插件。
- 禁用或移除插件后刷新 X，即可恢复原页面。

## 开发与验证

无需安装依赖或构建，浏览器直接加载 `manifest.json`、`inline.js` 和 `inline.css`。

安装 Node.js 后，在项目目录运行：

```sh
node checks/self-check.cjs
```

自动断言覆盖中文数字格式、新旧用户字段、fetch / XMLHttpRequest 响应读取、未知值与 0 的区分、过期处理、作者栏复用及扩展配置。模拟环境的断言不能替代所有浏览器和真实 X 页面的验收。

反馈问题时，请在本仓库创建 Issue，说明浏览器版本、插件版本、出现问题的页面类型，并提供必要截图。请勿上传 Cookie、登录令牌或包含这些内容的网络响应。
